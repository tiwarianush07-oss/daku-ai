## 3. Storage & Backup Cost Containment

### 3.1. Boot Volume Cap
- Oracle instances default to 47 GB boot volumes.
- DAKU documentation and deployment scripts explicitly warn **NEVER** to allocate boot volumes greater than 200 GB, as volumes exceeding 200 GB automatically incur monthly block volume storage charges (~$0.0255 per GB/month).

### 3.2. Local State Snapshot Rotation
- Backups generated by `scripts/backup.sh` are stored locally in `/var/backups/daku/` on the boot volume.
- The script enforces a **7-day retention policy** (`tail -n +8 | xargs -r rm -f`), ensuring backup archives cannot fill the disk or require additional paid block volume attachments.

## 5. Mandatory Steps to Ensure Zero Charges

To verify and maintain zero billing on Oracle Cloud:
1. **Account Tier**: Do NOT click "Upgrade to Corporate Paid Account". Keep the account in "Free Tier / Always Free" state.
2. **Budget Alert Configuration**:
   - In the Oracle Cloud Console, navigate to: **Billing & Cost Management** → **Budgets**.
   - Create a budget with **Target Monthly Amount: ₹1.00 ($1.00)**.
   - Set **Threshold: 1%** (triggering an instant email alert if charges reach ₹0.01).
3. **Avoid Paid Networking Add-ons**:
   - Do NOT configure Oracle NAT Gateways (charged per hour).
   - Do NOT provision Flexible Public Load Balancers (outside the single Always Free load balancer allowance).
   - Terminate TLS directly using the built-in Nginx reverse proxy on the compute instance itself.
